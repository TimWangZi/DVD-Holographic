# 普通 CD-R 刻录机正四面体全息实验

本项目直接生成正四面体六条棱的三维计算全息图，并输出普通 CD-R 刻录机可接受的 WAV/CUE 音轨。已跳过方案中的前置光栅阶段；包含三维点源计算、螺旋坐标映射、CIRC 数据位置预补偿、正向编码检查和光学重建预测。

当前已完成软件生成与验证，**普通刻录机写出的盘片能否重建目标像仍需实盘测试**。材料参数、标记形状和实盘几何使用可修改的先验；所有重建图片均为仿真，不是测量结果。

## 直接刻录已有结果

默认结果位于 `output/tetrahedron/`。将其中的 `tetrahedron.cue` 与 `tetrahedron.wav` 保持在同一目录，在 ImgBurn 中选择 **Write image file to disc → 打开 CUE → SAO/DAO**，用空白 CD-R 烧录一条 AUDIO 音轨。不要作为文件写入数据盘，不要归一化或重采样。WAV 是记录结构的载体，不要试听。

本次默认音轨长 **7 分 38.56 秒**，包含 **34,392 个扇区**；WAV 大小 **80,890,028 字节**。完整步骤、命令行替代方式及光学布置见 [刻录与测试说明](BURNING.zh-CN.md)。

## 重新生成

使用 Python 3.10 或更新版本，在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python -m cdholo build --config configs/tetrahedron.json --output output/tetrahedron
python -m unittest discover -s tests -v
```

生成命令只写本地结果，不操作光驱。同一输出目录的同名生成文件会被更新；比较不同参数时应更换 `--output` 目录。完整配置在 [configs/tetrahedron.json](../configs/tetrahedron.json)，每次输出均保存一份 `config.json` 快照。

## 参数

局部坐标约定：`x` 为窗口切向，`y` 为径向向外，`z` 为盘面反射一侧的实像距离。所有 JSON 数值的单位如下；CD 标准中的 44.1 kHz、每帧 588 通道位等格式常量不作为可变物理参数。

| 配置组 | 主要参数与单位 | 默认值 |
| --- | --- | --- |
| `disc` | 程序区起始半径 mm、轨距 μm、1× 基准线速度 m/s、起始角 °、帧原点偏移、螺旋方向、容量 min、尾部余量 s、背景字节 | 25 mm，1.6 μm，1.2 m/s，80 min |
| `patch` | 中心半径 mm、方位角 °、窗口切向/径向尺寸 mm | 28 mm，0°，4 × 4 mm |
| `target` | 四面体棱长 mm、成像距离 mm、横向偏移 mm、三轴旋转 °、每棱采样点数、点源随机相位及种子 | 棱长 4 mm，距离 300 mm，偏移 `[0, 5]` mm，每棱 33 点 |
| `optics` | 重建波长 nm、照明角 °、`gaussian`/`uniform` 光斑、光斑半径/中心 mm | 632.8 nm，法向入射，高斯半径 `[1, 1]` mm |
| `media` | 薄膜或直接复反射模式、各层 `[n, k]`、厚度 nm、偏振、内部入射角 °、标记宽度/边缘收缩 μm | 标记宽 0.5 μm，每端收缩 0.06 μm；具体材料先验见配置 |
| `optimization` | 候选输入字节、二值占比、反转、CIRC 位置预补偿开关 | `[13, 170]` 即 `0D/AA`，占比 0.5，预补偿开启 |
| `simulation` | 切向/径向网格 μm、重建图边长像素数、观察跨度 mm、焦面偏移 mm、完整通道样本帧数、处理块帧数 | `[4, 1.6]` μm，320 像素，5 mm，`[-2, 0, 2]` mm，128 帧 |

高斯 `beam_radius_mm` 为 **1/e² 强度半径**，默认强度直径为 2 mm。`disc.linear_velocity_m_s` 描述 1× 物理线密度，不随 8×/16× 刻录速度乘倍。`land_r`、`mark_r` 在 `reflection_mode = "direct"` 时为 `[实部, 虚部]`；薄膜模式使用被动材料的 `n + i k` 约定。修改波长时应同步修改材料光学常数；代码不会自动补齐未知色散。

## 编码与光学模型的范围

CIRC 按 ECMA-130 附录 C 实现校验及交织，EFM 使用附录 D 码表。算法先将三维目标的复场投影到二值条纹，再选取输入字节并反向补偿 CIRC 数据位置。这里的“优化”是**受约束二值投影与位置补偿**，尚未实现对完整刻录链路反复求解的全局光场优化器。

全窗口光学预测使用真实 CIRC 输出的 32 个符号，包括校验符号，并加入帧同步与名义子码的转换密度。EFM 码字转换计数准确，符号间合并位使用相邻码字的合法候选平均；同步边界的合并位使用近似。其沿轨标记占比近似为 `0.5 - trim_T × transition_density`，再乘标记宽度/轨距得到有效面积，经复反射模型及标量 Fresnel 积分传播。这是**粗粒度面积模型**，没有对全窗口每个通道位、沟槽或标记边缘逐一传播。

另有 128 帧的完整通道样本采用合法的确定性 DSV 合并位策略，检查 3T–11T 游程并输出 NRZI。样本状态从配置实现的初值开始，不代表捕获了真实刻录机的固件状态。普通刻录机仍自行执行编码与写入策略；RAW/DAO 不赋予主机任意指定 pits 的能力。

默认染料未记录态借用文献在 780 nm 的 `2.11 + i0.077`，在缺少色散数据时用于 632.8 nm 初值；记录态折射率、层厚变化及边缘收缩均为假设。`edge_trim_um = 0` 时此面积模型的输入相关对比度消失，仍可能存在孔径衍射背景。没有标定这些参数，就不能把仿真亮度或图像对比度当作实盘效率。

## 已完成验证

13 项单元测试通过，覆盖 CIRC/EFM、延迟位置、游程、WAV 字节序、几何、正四面体边长、薄膜极限和传播焦点方向。默认生成结果中 **1,470,031 个受控数据符号经正向 CIRC 后为零错位**；128 帧通道样本共 75,264 位，游程范围 3T–11T。详细数值以对应结果的 `manifest.json` 为准。

这些检查证明软件数据路径与所选参考模型一致，不替代实盘几何、材料及重建测试。
