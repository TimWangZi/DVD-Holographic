# DVD-R 全息的几何标定

建议先标定，再烧录正式四面体。当前的 24 mm 起始半径、0.74 μm 轨距和 133.3 nm 通道位长只是初值。几何误差会逐圈积累，导致全息条纹错位；软件编码检查通过不能消除这种误差。

本次增加的是 **DVD-R 标定镜像、照片取点、几何拟合和配置导出**。它使用与全息镜像相同的扇区映射、扰码反补偿和 `93/A5` 数据模式。盘面照片用于几何标定，不会被当成折射率或复反射相位测量。DiscImageStudio 也将照片矫正和几何拟合分开处理；其[标定说明](https://raw.githubusercontent.com/JiaFeiMiao-K-Cat/DiscImageStudio/main/docs/CALIBRATION.md)和[物理模型审查](https://raw.githubusercontent.com/JiaFeiMiao-K-Cat/DiscImageStudio/main/docs/PHYSICAL_MODEL_AUDIT.md)指出，仅靠一条线的拟合低残差不足以证明物理参数唯一。

## 你先做这几步

在项目目录运行以下命令。默认的标定镜像也会随本次实现生成，可以直接使用；改变标定参数后再重新生成。

```powershell
python -m cdholo calibration-build
```

结果位于 `output/calibration_dvd/`：

| 文件 | 用途 |
| --- | --- |
| `dvd_calibration.iso` | 刻录到一张新的单层 DVD-R |
| `target.json` | 这一张标定盘的生成参数及特征定义；必须保留 |
| `target_preview.png` | 理想图案和特征编号，辅助辨认实盘 |
| `measurements_template.csv` | 手工录入测量数据的模板；不是实测结果 |

使用 ImgBurn 的 **Write image file to disc** 打开 ISO，以 DVD-R DAO 写入、封盘并完成 Verify。使用计划烧录全息图的同一刻录机、同品牌/MID/批次盘片及相同速度。不要提取 ISO 内文件后重建镜像，也不要把 ISO 作为普通文件烧入另一张盘。

正式操作过程见 [DVD-R 刻录说明](DVD-R.zh-CN.md)。标定盘本身可以反复拍照和取点，不需要每次修改测量点就重烧。

## 怎样拍照片

优先使用能清楚看到记录图案的正视扫描图，或从盘面正上方拍摄。保留完整的实体外缘和中心孔；外径不是刻录区的外径。使用原始图像，不要裁掉盘缘、拉伸图片或用美颜/透视自动修图。

拍摄实际读取/照明的 **数据面**，不要拍标签面，也不要左右镜像图片或使用镜像自拍。让相机光轴尽量垂直盘面，盘片放平，避免广角近距离拍摄。调整柔和光照，让圆环和两条线的边缘可见，同时避免反光过曝。反光挡住一处时，可以调整照明重拍同一张盘。

取点工具根据实体外缘确定尺度并检查中心孔。它用于近正视图像的校正；明显斜拍、强透视和镜头畸变不能由一个漂亮的圆形预览自动证明已消除。出现明显的外缘/孔缘不一致时，应重拍。

`--diameter-mm` 是实体盘片外径，12 cm 盘默认 120 mm。如果有可信的卡尺测量，可填写实际值。不要把 24 mm 数据区起始半径或约 58 mm 记录外半径填在这里。照片中没有物理刻线或尺标，程序不会凭空获得绝对毫米尺度。

## 怎样取点

```powershell
python -m cdholo calibration-measure --image photo.jpg --target output/calibration_dvd/target.json --output measurements.csv --diameter-mm 120
```

打开的是本地测量窗口。按窗口提示先标记实体外缘至少 8 个点，再标记直径约 15 mm 的中心孔边缘至少 8 个点；不要选成透明塑料环。点位应分布在一整圈，避开阴影和反光。核对校正结果后，依次测量标定特征。

左键添加点，右键或 Backspace/Delete 撤销，Enter 完成当前特征。某个特征尚未取点时按 Enter 可以跳过；Esc 或关闭窗口会取消，不写最终 CSV。可用工具栏缩放和平移；选中这些导航工具时点击不会记录测量点，取点前应退出导航工具。

默认图案在约 24.7–33.5 mm 环带内，包含九个圆环和两条不同宽度的辐条。它覆盖四面体所在的约 26–30 mm 区域，并在两侧留有测量范围。

- 圆环编号 `R01` 到 `R09`，按从内到外识别。测量的是每个亮/暗环带的 **外缘**，不是中线或内缘。默认中心半径为 25–33 mm、环宽 0.16 mm，因此理想外缘为 25.08、26.08……33.08 mm。实际半径由照片测量，不要把这些理想值当作实测填入。
- 辐条编号 `S01`、`S02`，理想方位分别为 0°、120°，宽度不同以辅助辨认。测量辐条的 **中线**。从内向外沿同一条线连续点选；即使它弯曲，也沿实际曲线测量。
- 尽量覆盖全部圆环，每圈至少 6 个分布在不同方位的点。辐条至少需要 8 个按半径严格递增的点，推荐每条 20–40 点；急弯处加密，使相邻点的角度变化不超过 90°。
- 圆环与辐条交叉处会加宽或覆盖边缘，反光处会模糊。跳过这些位置，换到清楚的区域；不要把两条辐条混接成一条。

程序保存毫米坐标 CSV，同时输出 `measurements.clicks.json`、`measurements.qa.json` 和 `measurements.preview.png`，分别记录原始点击、校正检查和叠加预览。重新调整外缘、中心孔或尺度后，应重新测量，不要沿用旧校正坐标。可通过 `--features R01,R05,R09,S01,S02` 只选择部分特征；实际接受的编号以同一目录的 `target.json` 为准。已有点击记录可以用 `--clicks-json measurements.clicks.json` 重放，不再打开交互窗口。

如果倾斜或扭曲太重，无法沿同一辐条连续追踪，先只量圆环做粗标定。不要跨过一段不清楚的多圈绕转后，假定程序能猜出漏掉了多少圈。

手工填写 CSV 时，关键列为 `feature_id`、`kind`、`click_index`、`x_mm`、`y_mm`，辐条还需要 `angle_unwrapped_deg`。连续角度不能简单限定在 0–360°；越过一整圈时要继续加减 360°。交互工具会根据连续取点生成这一列，但不能发现你漏掉的一整圈。`sigma_mm` 可以填写独立评估的点位不确定度；不要为了使报告看起来精确而任意缩小它。

## 先粗标定还是直接精标定

能清楚识别所有圆环和连续辐条时，可在同一张盘上完成测量后直接运行精标定：

```powershell
python -m cdholo calibration-fit --target output/calibration_dvd/target.json --measurements measurements.csv --mode refine --direction auto --output output/calibration_fit
```

只有圆环可靠，或辐条已经绕转得难以识别时，先运行：

```powershell
python -m cdholo calibration-fit --target output/calibration_dvd/target.json --measurements measurements.csv --mode coarse --output output/calibration_coarse
```

粗标定将通道位长固定在生成配置的先验值，使用圆环的位置修正有效起始半径和轨距。它提供下一次标定的初值，不声称独立测出了通道位长。用粗标定导出的配置生成 **新的** 标定图案：

```powershell
python -m cdholo calibration-build --config output/calibration_coarse/calibrated_config.json --output output/calibration_dvd_round2
```

刻到新空白盘后，配对使用新盘的 `target.json` 和照片，再做精标定。不能拿旧盘照片套用新生成记录；重复拟合同一张旧照片也不等于完成一次重新刻录验证。

## 结果应该怎样判断

拟合目录中保存 `calibrated_config.json`、`fit_report.json` 和 `fit_residuals.png` 诊断图。先检查：是否使用了正确盘片的生成记录，测量是否跨越足够多的半径，圆环是否量到了外缘，以及预测是否与整条已测和未测辐条一致。输出参数的小数位数不代表实际测量精度。

程序至少需要两个不同半径的已知圆环，半径跨度不小于 0.5 mm；每环至少 6 点并覆盖超过半圈。默认自动判断方向的精标定还需要 **两条可区分的连续辐条**，每条至少 8 点、跨度不小于 0.5 mm，并有共同径向范围。实际操作建议使用更多圆环和更大覆盖范围，而不是刚好凑齐最低数量。

`--direction auto` 利用两条非对置辐条的相对位置判断盘面坐标的方向，并把拟合方向写入 `spiral_direction`。它避免把方向相反的图案硬拟合成错误的轨距。算法不能区分“真实坐标方向反转”和“照片被软件镜像”，所以仍必须使用数据面的未镜像照片。只有方向已由独立依据确定时，才使用 `--direction 1` 或 `--direction -1`；这种显式模式可使用一条辐条，但一条线不能独立判断方向。

报告中的 `ring_radial_rms_um` 是环的径向残差，`trace_tangential_rms_um` 是辐条的切向残差。报告还包含雅可比矩阵的秩与条件数、条件标准误差和留出点验证。条件标准误差基于输入误差与当前模型，未包括所有镜头、取点偏差、标记边缘偏移和盘片间差异。报告保留 `winding_ambiguity_excluded: false`，表示没有凭稀疏角度数据证明排除了所有绕圈候选。

圆环主要约束数据位置对应的半径关系。对均匀螺旋模型，可以写成 `r² = A + B × N`，其中 `N` 是通道时钟位置，`B` 与轨距和位长的乘积有关。辐条的弯曲提供角度变化信息，帮助分开这两个尺度。若数据不足、角度存在绕圈歧义或多个解难以区分，增加其他半径的清晰点位，或先按粗标定结果重刻一张盘。

起始半径和通道时钟偏移存在等效性。程序将 `channel_offset_bits` 固定为 0，报告的是在这个约定下能用于几何映射的有效参数；不能把它们全部解释为独立测量的盘片制造尺寸。照片旋转角仅写入报告，导出配置保留原来的 `start_angle_deg`。下一张盘的绝对方位仍需转盘寻找，不能保证复刻在同一外观方向。

保留几处清楚的位置不参加拟合，检查预测是否也贴合这些点。最终再用修正参数刻一张验证标定盘，检验新的圆环/辐条是否符合预测。若残差随半径有系统趋势，恒定轨距模型可能不够；不能靠增加显示小数位掩盖这种偏差。

全盘照片适合修正粗几何。比如 120 mm 盘片在 6000 像素宽照片上平均约为 20 μm/像素，即使能做亚像素取点，也不能仅凭该数字证明获得微米级绝对精度。全息条纹对位置误差更敏感，因此几何拟合通过后，仍需通过实盘重建检验；报告的点位残差不是成像成功保证。

报告的 `hologram_registration_reference` 根据当前四面体尺寸、距离、波长和孔径给出保守的最短条纹周期，并把周期的 1/8 作为约 π/4 相位误差对应的位置参考。`within_heuristic_budget` 为 false，说明当前点位残差相对于这项参考仍然过大，应提高照片/扫描清晰度、检查取点和系统偏差；为 true 也只说明这项粗略检查通过，未包含尺度误差、镜头畸变及换盘漂移。粗标定没有角度留出检查，该项不作通过判断。

## 用标定参数重算四面体

```powershell
python -m cdholo build --config output/calibration_fit/calibrated_config.json --output output/tetrahedron_dvd_calibrated
```

烧录新目录的 `tetrahedron_dvd.iso`。保留旧结果，便于在相同照明、距离和曝光下比较。默认光学设置仍是 632.8 nm、约 2 mm 高斯强度直径、半径 28 mm 附近照明、反射侧约 300 mm 处观察。

## 哪些参数还不能这样获得

照片标定只更新几何部分，不会改写 `media` 中的折射率、膜厚、标记宽度或边缘收缩量。

- 盘面明暗取决于照明、观察方向、相机响应和衍射，不能直接换算成复折射率 `n + ik`。
- 只测衍射强度通常只能约束有效反差的大小；它不能唯一分离复反射相位、染料折射率、膜厚和标记形状。
- 要更新复反射系数，需要相同波长、角度和偏振下的反射/干涉测量；有测量值后可用 `reflection_mode = "direct"`，将复反射系数的实部、虚部分别填入 `land_r`、`mark_r`。直接测量的对象必须与模型中的记录态/未记录态定义一致，不能把两种宏观数据块的平均反射系数未经转换就当作微观标记系数。

本轮先完成可实际操作的几何标定。记录反差仍使用有来源标签的先验，并保留零边缘收缩的敏感性对照；它不会因为几何标定完成而自动变成实测参数。
