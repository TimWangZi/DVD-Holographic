# DVD-R 正四面体全息刻录与测试

DVD-R 版本输出 `output/tetrahedron_dvd/tetrahedron_dvd.iso`，用于普通 DVD 刻录机和空白单层 4.7 GB DVD-R。它保留正四面体六条棱、632.8 nm 重建光和 300 mm 实像距离，重新实现 DVD 的数据编码与螺旋映射。CD 版本的 WAV/CUE 仍在旧目录，本次应烧录新的 ISO。

## 生成与烧录

在项目根目录执行：

```powershell
python -m cdholo build --config configs/tetrahedron_dvd.json --output output/tetrahedron_dvd
python -m unittest discover -s tests -v
```

ISO 的每个逻辑扇区为 2048 字节。它包含最小 ISO9660 文件系统：内圈元数据、`README.TXT` 和固定位置的 `HOLOGRAM.BIN`。挂载后看到这些文件属于正常现象；光学图样由原镜像中数据的**扇区位置及内容**共同决定。不要提取文件再重建镜像，也不要把 ISO 当普通文件放到另一个数据盘中。

1. 放入空白单层 **DVD-R**，选择支持 DVD-R 写入的光驱。
2. ImgBurn 选择 **Write image file to disc**，Source 打开 `tetrahedron_dvd.iso`。
3. 确认目的介质是 DVD-R、镜像扇区为 2048 字节，使用 **DAO** 单次写入并完成封盘。不要追加会话，不要改用 DVD+R、DVD-RW 或双层介质。
4. 选择盘片和光驱共同支持的速度，例如列表中存在的 4× 或 8×；记录请求速度及日志里的实际速度。启用 **Verify**，等待写入、封盘和校验全部结束。
5. 保存刻录日志及输出目录的 `config.json`、`manifest.json`。

镜像写入入口与 Verify 用法见 [ImgBurn 官方指南](https://forum.imgburn.com/topic/61-how-to-write-an-image-file-to-a-disc-using-imgburn/)。当前程序只生成和验证本地文件，不会操作光驱。短镜像写完后，DVD-R 刻录机还可能写入较长的 Lead-out；完成时间和可见记录外圈不只由 ISO 文件大小决定。

## 默认光学布置

| 项目 | 默认参数 |
| --- | --- |
| 光源 | 632.8 nm 相干准直光 |
| 入射 | 接近法向，照射 DVD 数据面 |
| 高斯光斑 | 1/e² 强度半径 1 mm，即强度直径约 2 mm |
| 图样窗口 | 中心半径 28 mm，切向 × 径向为 4 × 4 mm |
| 寻找窗口 | 在半径约 26–30 mm 环带缓慢转动盘片，找出未知的实际方位角 |
| 实像距离 | 反射侧距盘面约 300 mm |
| 像中心 | 相对镜面反射点沿窗口径向向外约 5 mm，切向偏移 0 mm |
| 三维目标 | 棱长 4 mm 的正四面体，六条棱均参与计算 |

法向入射与反射共路，可用分光镜把返回光引到屏幕或相机。先对准窗口中心，再观察上述离轴位置。不要为避开光源而随意大幅倾斜盘片；改变照明角应同步修改配置并重新生成。使用屏幕或相机定位，避开直接光及镜面反射光入眼。

默认有效孔径较小，景深可能覆盖大部分四面体；在 298–302 mm 移动屏幕时，清晰度变化未必明显。单张屏上图像不能单独证明立体视差。高斯光斑降低硬孔径边缘的衍射背景；如果实际光斑是均匀硬边光斑，应将 `beam_profile` 改为 `uniform` 后比较预测。

## 与 CD 版本不同的编码

DVD 输入为逻辑数据扇区，经过数据帧头、IED/EDC、扰码、PI/PO 纠错、PO 行交织、EFMPlus 8→16 调制、同步和 NRZI 后形成记录标记。软件反向抵消数据扰码，使目标字节出现在指定的调制位置；实际刻录机依然负责物理编码、DSV 选择、伺服和写入脉冲。默认选用 `0x93/0xA5` 两种模式，已检查四个起始状态的重复循环和交替序列，没有持续直流漂移；配置中仍可更换候选字节。

配置采用单层 DVD-R 数据区起点 `PSN = 0x030000`，将逻辑 `LBA = 0` 锚定在名义半径 24 mm。每扇区为 38,688 通道位，16 扇区组成一个 ECC 块；这套空间映射计入同步、PI 和 PO 开销。DVD-R 标准规定的名义轨距为 0.74 μm，平均通道位长为 133.3 nm；这些是几何初值，不能代替目标盘片的实测值。依据为 [ECMA-359 §§10、16–24 和附录 G](https://www.ecma-international.org/wp-content/uploads/ECMA-359_1st_edition_december_2004.pdf)。DAO 的连续写入模型不在每个 ECC 块之间额外插入任意间隙。

全窗口光学计算使用编码后字节的状态平均 EFMPlus 跳变密度及有效标记面积。另有一个 ECC 块的完整通道样本，用于检查调制与游程。两者要分开理解：完整通道样本不等于全盘逐通道位光学传播，也不等于已读出某台刻录机实际选择的 DSV 状态。

没有禁用扰码、ECC 或固件写入控制，也未把 `.iso` 扩展名解释为最终通道位流。DVD-R 的 Lead-in、Lead-out、预刻沟槽与 Land Pre-Pit 仍由介质和设备决定。实际起始角会旋转图样；轨距、位长和半径误差会累计成跨圈错位，可能造成条纹弯曲或散焦。

## 材料参数来源

本次不沿用 CD-R 在 780 nm 的染料数值。默认改用 DVD-R 红光染料范围内的假设点，并保留所有参数的独立配置。

| 参数 | 默认值 | 依据或性质 |
| --- | --- | --- |
| 未记录染料 | `n + ik = 2.3 + 0.05i`，厚 70 nm | 根据 DVD-R 在约 650 nm 的公开范围选取；迁移到 632.8 nm 的先验 |
| 记录后染料 | `1.7 + 0.02i`，厚 60 nm | 未实测假设 |
| 反射金属 | 银，`0.05625293 + 4.2760281i` | Johnson–Christy 数据在 632.8 nm 的线性插值；具体盘片是否为银仍是假设 |
| 聚碳酸酯 | `n = 1.58` | 基板初值；当前模型不计算整个基板的像差 |
| 标记宽度 | 0.30 μm | 未实测的有效几何宽度 |
| 标记每端收缩 | 0.025 μm | 未实测的有效边缘参数 |

DVD-R 染料的范围依据公开专利 [US20060007843A1](https://patents.google.com/patent/US20060007843A1/en)：其给出 650 nm 附近可选的 `n = 1.8–2.6`、`k = 0–0.10` 和 50–300 nm 膜厚。这里采用的是其范围作为先验，没有把专利实施例或优选范围当成用户盘片的测量值。

银的数据来自 [Johnson 与 Christy, Physical Review B 6, 4370 (1972)](https://doi.org/10.1103/PhysRevB.6.4370)。公开的[数据转录](https://raw.githubusercontent.com/polyanskiy/refractiveindex.info-database/main/database/data/main/Ag/nk/Johnson.yml)在 616.8 nm 和 659.5 nm 分别给出 `(0.06, 4.152)`、`(0.05, 4.483)`。代码使用被动材料 `n + ik`，并通过薄膜反射计算得到复反射系数；不能直接把 `n` 当作反射率。

输入相关的粗尺度反差依赖标记形状假设。把 `edge_trim_um` 设为零时，当前有效面积模型的反差会消失；仍可能看到孔径背景。这项对照保留在仿真中。是否能用实际 DVD-R 重建四面体，仍需本次实盘测试。

## 测试结果与读回

以当前输出目录的 `manifest.json` 为准查看镜像字节数、配置、SHA-256、编码校验和仿真指标。`overview.png`、`focus_stack.png` 均为模型预测。

ImgBurn Verify 检查逻辑扇区是否与原 ISO 一致。如果将盘读回为 2048 字节/扇区的镜像，比较原镜像长度范围内的数据；读回文件可能额外包含尾部填充，不能仅凭整个文件长度或整文件哈希不同认定失败。逻辑数据一致仍不等于微观标记位置和材料模型已经验证。

请保留盘片品牌/批次、MID、光驱型号/固件、实际刻录速度、波长、光斑尺寸、盘到屏距离，以及含镜面反射点和设计像区域的屏幕照片。
